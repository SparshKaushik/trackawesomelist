JavaScript tools

Charting libraries

  • Apache ECharts (⭐67k) - Highly customizable and interactive charts ready for big datasets.
  • ApexCharts - Modern & Interactive SVG Charts.
  • billboard.js (⭐6k) - Reusable D3.js-based chart library with SVG and Canvas rendering, maintained by NAVER.
  • C3.js (⭐9.3k) - D3-based reusable chart library.
  • Chart.js - Charts with the canvas tag.
  • Chartist.js - Responsive charts with great browser compatibility.
  • Charts.css (⭐6.6k) - CSS framework that styles HTML tables as charts.
  • dc.js (⭐7.4k) - Multi-dimensional charting built to work natively with crossfilter.
  • dxcharts-lite (⭐101) - Flexible financial charting library based on HTML5 canvas.
  • Dygraphs - Interactive line charts library that works with huge datasets.
  • Epoch (⭐4.9k) - Perfect to create real-time charts.
  • Frappe Charts (⭐15k) - Simple, responsive SVG charts with zero dependencies.
  • Frappe Gantt (⭐6.1k) - Simple, interactive SVG Gantt chart library.
  • G2 (⭐13k) - An interactive and responsive charting library based on the grammar of graphics, maintained by Alibaba.
  • Glyph (⭐3) - Deterministic chart library that renders the same JSON spec to identical SVG on every platform, with DuckDB inside and an MCP server for AI agents.
  • Google Charts - Interactive charts for browsers and mobile devices.
  • GraphicsJS - Lightweight JS graphics library with intuitive API, based on SVG/VML.
  • Lightweight Charts (⭐17k) - Performant HTML5 canvas financial charts, from TradingView.
  • lit-line (⭐22) - SVG Line Chart Web Component - light, fast, interactive & fully responsive.
  • MetricsGraphics.js - Optimized for time-series data.
  • NVD3 (⭐7.2k) - A reusable charting library written in d3.js.
  • Observable Plot (⭐5.4k) - A JavaScript library for exploratory data visualization.
  • Plotly.js (⭐18k) - Powerful declarative library with support for 20 chart types.
  • roughViz (⭐7.2k) - Sketchy, hand-drawn style charts for the browser, based on Rough.js.
  • TechanJS - Stock and financial charts.
  • TOAST UI Chart (⭐5.4k) - Complete library with support for legacy browsers.
  • Unovis (⭐2.9k) - Modular data visualization framework for React, Angular, Svelte, Vue and vanilla TypeScript, by F5.
  • uPlot (⭐11k) - Small, fast canvas-based charts for time series, lines, areas, OHLC and bars.
  • Vizzu (⭐2k) - Library for animated data visualizations and data stories.

Charting libraries for graphs

  • 3d-force-graph (⭐6.4k) - 3D force-directed graph component using Three.js/WebGL.
  • Cola.js - A tool to create diagrams using constraint-based optimization techniques. Works with d3 and svg.js.
  • Cytoscape.js - JavaScript library for graph drawing maintained by Cytoscape core developers.
  • dagre (⭐5.8k) - Directed graph layout library for JavaScript.
  • diagram.js (⭐1.9k) - Javascript diagram library serving as the basis for camunda's online BPMN modeler.
  • elkjs (⭐2.8k) - Eclipse Layout Kernel (ELK) graph layout algorithms for JavaScript.
  • G6 (⭐12k) - Graph visualization library powered by Javascript & Typescript, maintained by Alibaba
  • JointJS (⭐5.4k) - SVG-based JavaScript diagramming library for interactive diagrams and graph editors.
  • Sigma.js - JavaScript library dedicated to graph drawing.
  • Uber React Digraph (⭐2.6k) - React.js based directed graph library maintained by UBER.
  • VivaGraph (⭐3.9k) - Graph drawing library for JavaScript.
  • Vizdom (⭐193) - A declarative graph layout and rendering engine for Javascript/Typescript powered by Rust/WebAssembly.
  • Vue Flow (⭐6.9k) - Flowchart and node-based graph component for Vue 3.
  • X6 (⭐6.7k) - Diagramming library for DAGs, ER diagrams, flowcharts and other graph editors, maintained by Alibaba.
  • xyflow (⭐39k) - React Flow and Svelte Flow: libraries for building node-based editors, flow charts and interactive diagrams.

Maps

  • CanvasGlobe (⭐0) - Interactive Canvas 2D globes and flat world maps for JavaScript and React.
  • Cesium (⭐16k) - WebGL 3D globes and maps.
  • DataMaps (⭐3.8k) - Interactive SVG maps using D3.js.
  • Deck.gl - WebGL framework for visual exploratory data analysis of large datasets.
  • Dipper (⭐29) - Map application development framework powered by L7, maintained by Alibaba.
  • globe.gl (⭐3.2k) - UI component for globe data visualization using Three.js/WebGL.
  • Globedots (⭐0) - Dot-matrix WebGL2 globe in 17 kB with markers, arcs, labels, heat maps, and a day-night line.
  • L7 (⭐4.1k) - Large-scale WebGL-powered Geospatial Data Visualization analysis framework, maintained by Alibaba
  • L7 Plot (⭐91) - Geospatial Visualization Chart Library, maintained by Alibaba
  • Leaflet - JavaScript library for mobile-friendly interactive maps.
  • Mapael (⭐1k) - jQuery plugin based on raphael.js to display vector maps.
  • MapLibre GL JS (⭐12k) - WebGL-based interactive vector tile maps in the browser; community fork of Mapbox GL JS.
  • maptalks.js (⭐4.5k) - Pluggable JavaScript library for integrated 2D/3D maps.
  • OpenLayers (⭐13k) - Library for interactive web maps with support for many data sources, formats and projections.
  • Pharos AI - Open-source OSINT conflict-tracking dashboard with geospatial visualization using Deck.gl, MapLibre, and React. (Source Code (⭐182))
  • Potree (⭐5.6k) - WebGL point cloud viewer for large datasets such as LiDAR scans.
  • React Simple Maps (⭐3.4k) - Composable SVG map charts for React, based on d3-geo and TopoJSON.
  • react-map-gl (⭐8.5k) - React components for MapLibre GL JS and Mapbox GL JS, maintained by vis.gl.
  • VectorAtlas - Free, 80KB SVG world map with one path per country, id-keyed by ISO 3166-1 alpha-2 code, ready for choropleths.

  • Markmap (⭐13k) - Builds interactive mind maps from Markdown.
  • Mermaid (⭐91k) - Generate diagrams and flowcharts from markdown-like text definitions, with a live editor.
  • Penrose (⭐8k) - Creates diagrams from mathematical notation in plain text, from Carnegie Mellon University.
  • PGFPlots (⭐257) - TeX package for drawing 2D and 3D plots directly in LaTeX documents.
  • PlantUML (⭐13k) - Generates UML, Gantt, mind map and other diagrams from plain text.
  • WaveDrom - Draws timing diagrams and waveforms from simple textual descriptions.

Other tools

Tools that are not tied to a particular platform or language.

  • ChartDB (⭐23k) - An Open-source tool to visualize database schemas and generate ER diagrams from a single query.
  • Charted (⭐2.7k) - A charting tool that produces automatic, shareable charts from any data file.
  • csvtodashboard - Turn a CSV or Excel file into an auto-built dashboard in the browser - client-side, no upload.
  • Cytoscape (⭐731) - Desktop platform for network analysis and visualization, widely used in bioinformatics.
  • DAC (⭐776) - Dashboard-as-code tool that builds interactive dashboards from YAML and TSX definitions
  • Data Formulator (⭐18k) - AI-assisted tool for transforming data and creating visualizations, from Microsoft Research.
  • draw.io (⭐8.5k) - Client-side JavaScript editor for flowcharts, network, UML and other diagrams.
  • ERD Lab - Free cloud based entity relationship diagram (ERD) tool made for developers.
  • FlameGraph (⭐20k) - Stack trace visualizer that generates interactive SVG flame graphs from profiling data.
  • Gephi (⭐6.7k) - An open-source platform for visualizing and manipulating large graphs
  • gnuplot - Command-line driven program for 2D and 3D plots, with many output formats.
  • Gource (⭐13k) - Animated visualization of software version control history.
  • Graphviz - Open source graph visualization command line tool and library. From input text to SVG,PDF,interactive web graph browser.
  • ink-uplot (⭐1) - Render uPlot charts in the terminal (React Ink) with truecolor Unicode and kitty/sixel/iTerm2 graphics.
  • Kepler.gl - Geospatial analysis tool for large-scale data sets.
  • LabPlot (⭐486) - KDE application for interactive scientific plotting, data analysis and visualization.
  • Orange (⭐5.7k) - Visual programming tool for data mining, machine learning and interactive data visualization.
  • Plotivy - Scientific data visualization tool, with AI-generated reproducible Python code, and research-oriented design best practices built in.
  • QGIS (⭐14k) - Desktop geographic information system for viewing, editing, analyzing and mapping geospatial data.
  • RATH (⭐4.7k) - Automatic Exploratory Data Analysis & Data Visualization tool which is powered by an AI-assisted Augmented Analytics engine.
  • RAW - Create web visualizations from CSV or Excel files.
  • Resseract Lite (⭐7) - A Data Analytics and Visualization Tool with flexible architecture to visualize and analyse data
  • Sampler (⭐15k) - Terminal dashboard that runs shell commands and visualizes their output, configured with YAML.
  • SandDance (⭐7.1k) - Visual data exploration and presentation with animated unit visualizations, from Microsoft Research.
  • sankeydiagram.net - Web app for creating and sharing Sankey diagrams of flows and budgets without code.
  • Spark (⭐6.1k) - Sparklines for the shell. It has several implementations in different languages (⭐6.1k).
  • Squey - Visualization software for exploring and understanding large amounts of tabular data (using parallel coordinates, timeseries and scatter plots).
  • VisiData (⭐9.3k) - Terminal spreadsheet multitool for exploring and arranging tabular data, with basic plotting.
