Awesome macros usage

Answers why the lisp shines, killer features in action

  • core.async (⭐2k) - transforms AST into CSP programs
  • cloroutine (⭐236) - suspends and continuations (coroutines)
  • missionary (⭐777) - a reactive dataflow programming toolkit
  • photon (⭐7) - realtime web, like Meteor, but for Clojure(Script)
  • metaclj (⭐82) - staged compilation
  • meander (⭐971) - transparent data transformation using datastructure pattermatching
  • proteus (⭐112) - introduce mutable variables (don't use, just learn how to map your mind into immutable world)

Advanced datastructures

  • specter (⭐2.6k): an elegant API for querying and transforming nested and recursive data
  • meander (⭐971): transparent data transformation (defined as pattern-matching)
  • Persistent AVL trees (⭐135): persistent sorted maps and sets with log-time rank queries
  • Finger Tree (⭐221): double-list, counted-double-list, counted-sorted-set
  • Hitchhiker Tree (⭐1.2k): create fast, snapshottable, massively scalable databases
  • Hierarchical set (⭐8)
  • Ordered (⭐266): ordered sets and maps
  • Lazy Map (⭐49): whose values are only calculated when accessed
  • Duratom (⭐230): persisted atoms
  • Durable Queue (⭐407): queue persisted on disk
  • bifurcan (⭐1k): linear map/set/list (stores entries contiguously in memory), ;writtern in java, but test suite (read: usage examples) in clojure (⭐1k)
