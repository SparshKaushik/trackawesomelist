10. Awesome Zsh Plugins

Plugins / superconsole - Windows-only

  • aws-login (⭐0) - Provides an aws-login command that starts an AWS session that only the current terminal and its child processes can use.
  • claude-sandbox (⭐4) - Points CLAUDE_CONFIG_DIR at a throwaway directory, so everything Claude Code reads and writes (settings, plugins, skills, history, credentials) stays inside that sandbox. Leave it, delete it, and your real setup is exactly as you left it.
  • curl-edit (⭐0) - Automatically open pasted cURL commands in an editor before executing them.
  • sf-shortcuts (⭐1) - Short, predictable commands for the Salesforce CLI (sf), with tab completion for Apex classes, components (aura/lightning) and orgs.
  • SparkleBIOS (⭐3) - Draws a retro 1995 PC BIOS boot screen with real system facts and cached health checks when a new ZSH session starts.
  • tab-start (⭐0) - adds starter entries to ZSH completion when you press TAB at a blank prompt. Uses fzf-tab (⭐5k) to render those entries and provides grouping, fuzzy search, and selection.
  • tmux-inside (⭐0) - A drop-in replacement for the oh-my-zsh tmux plugin that makes the tmux aliases work from inside a tmux session: instead of trying to nest a session (which tmux refuses), they switch to the target session, creating it detached in the current directory if needed.
  • utm (⭐0) - Adds a single utm command on top of utmctl, the command line tool that ships with UTM, with tab completion for subcommands, virtual machine names and snapshot names, and a --wait that utmctl does not have.
