7. Awesome Gemini Cli

Development Tools & Utilities

  • spillage (⭐3) - Finds API keys in the chats, logs and checkpoints Gemini CLI keeps under ~/.gemini/tmp and in the MCP servers of ~/.gemini/settings.json, redacts them in place, and installs BeforeAgent / BeforeTool / SessionEnd hooks (spillage guard install) that block a prompt with a key in it and reads of .env. Python, no dependencies, no network; also covers Claude Code, Codex CLI and Cursor.

MCP Servers

  • QRX (⭐2) - Turn a text prompt and a link into an artistic, branded QR code from Gemini CLI. Each code is checked to scan before it is returned and uses a hosted qrx.to short link. Remote Streamable HTTP with OAuth sign-in or an API key, or local stdio via npx -y @qrxcodes/mcp. MIT. Add with: gemini mcp add --transport http qrx https://qrx.codes/mcp.
  • Hoot Lens (⭐2) - Session replays and click heatmaps from real website visits. Find clicks that broke, jump to the JavaScript error and source line, and check whether a fix helped. Remote with OAuth (httpUrl: https://mcp.hootlens.com/mcp) or local with npx -y @hootlens/mcp. Demo with sample data, no sign-in: https://mcp.hootlens.com/demo.
