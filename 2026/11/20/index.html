4. Awesome LaTeX

Engines

  • XeTeX - TeX compiler that provides better unicode and font support than TeX/pdfTeX (i.e. you can use the fonts of your operating system instead of only TeX fonts).
  • SwiftLaTeX (⭐2.3k) - pdfTeX and XeTeX compiled to WebAssembly, so you can compile LaTeX entirely in the browser or embed a TeX engine in a webpage.

LaTeX formulas on the web

  • MathJax - JavaScript engine to render mathematical formulas on the web. The outcome looks really slick.
  • KaTeX - Math rendering library made by Khan Academy focusing on fast load times. All output is processed as plain HTML instead of fixed images.
  • MathLive - Web component for editing and displaying math with LaTeX, including virtual keyboards and MathML/speech export.

LaTeX-focused

  • BakomaTex - Commercial LaTeX editor that allows to edit your document both using its source code and WYSIWYG.
  • Gummi (⭐802) - Simple GTK LaTeX editor with a continuously updating live preview pane.
  • Texpile - Free and open-source desktop editor that edits LaTeX visually (like LyX) or by source with IntelliSense, with local compilation and built-in Git. Also supports Typst and Markdown.
  • LaTeX Editor (⭐34) - Single-executable desktop editor with live PDF preview, two-way SyncTeX, LaTeX-aware spell checking, and one-key project snapshots written as a standard Git repository. Needs a separate TeX distribution.
  • ModernTex - Native macOS LaTeX editor for academic writing, with synced source and PDF, plain-language error messages, submission-readiness checks, a visual TikZ designer and a table editor. Free 7-day trial, then a one-time $19.99.

Online editors

  • SciTeX Cloud (⭐2) - Self-hostable online editor with AI assistant integration, figure/table/citation management, real-time collaboration, and an MCP server (29 tools).
  • TeXlyre - Local-first, open-source browser editor for LaTeX with in-browser WebAssembly compilation, offline editing, and peer-to-peer collaboration via WebRTC.
  • CoCalc - Collaborative online LaTeX editor with real-time editing, TimeTravel history, and first-class SageTeX, PythonTeX, and Knitr support. Freemium.
  • VerbTeX - LaTeX editor for the browser plus native Android, iOS, and Windows apps, with optional offline compilation on device. Freemium.
  • Murfy - Online LaTeX editor with real-time collaboration and built-in AI assistance for writing and error fixing. Freemium.
  • Aldine - Self-hosted online editor with real-time collaboration in which every project is a Git repository, with branches in the editor and push/pull to GitHub, GitLab and Gitea.

Bibliography tools

  • Bibdesk - Great bibliography editor for .
  • betterbib (⭐841) - Command-line utility for improving your BibTeX files. Fetches information from online sources.
  • CrossRef Local (⭐5) - Local CrossRef database (167M papers) with full-text search, impact factor data, Python API for bibliography enrichment, and an MCP server (15 tools).
  • OpenAlex Local (⭐4) - Local OpenAlex database (284M scholarly works) with abstracts and semantic search for literature discovery, and an MCP server.
  • Biber - Modern bibliography processor for biblatex, with Unicode support and more flexible sorting than BibTeX.
  • BiblioAudit (⭐1) - Command-line tool to check, verify, and repair citations in BibTeX files across 12+ academic databases.
  • latexci BibTeX tools - Browser-based .bib cleaner (removes duplicates, normalizes author names, escapes special characters) plus DOI, arXiv, PubMed and ISBN to BibTeX lookups, with no install and no account.
