Commands & Extensions

  • Hermeneutic (⭐9) - Gemini CLI extension that reviews final-response wording for completion and certainty claims, then requests at most one evidence-focused revision through an AfterAgent hook. Runs the deterministic check locally.
  • since-cutoff (⭐3) - Gemini CLI extension (MCP server + skill) that tells the agent what changed in your Python dependencies since the model's training cutoff: a static diff of each library's public API between the release at the cutoff and the version your lockfile pins, with no model calls or API key. Install via gemini extensions install https://github.com/MohammadHijjawi97/since-cutoff.

  • OrcaPromptVault (⭐28) - Dated archive of the system prompts and tool schemas shipped AI agents send, including the one Gemini CLI itself puts on the wire.

  • Oh My Android (⭐3) - MCP server that lets Gemini CLI see and drive the Android Emulator on macOS: screenshots, UI tree in dp, tap/type, dark mode, RTL, font scale, logcat.
