Awesome Nix

A curated list of the best resources in the Nix community.


Nix (⭐17k) is a powerful package manager for Linux and other Unix systems that makes package management reliable and reproducible.

Please read the contribution guidelines before contributing.

Resources

Learning

  • Building a Rust service with Nix - An in-depth blog series about creating a Rust application with Nix.
  • Explainix - Explain Nix syntax visually.
  • How to Learn Nix - It's like a Let's Play, but for obscure software documentation.
  • Nix - A One Pager - A one page introduction to the Nix language.
  • nix-book - A comprehensive guide to NixOS hardening and configuration.
  • Nix from First Principles: Flake Edition - A modern crash-course to using Nix features, Flakes, and developing with Nix.
  • Nix in 100 Seconds - A YouTube video from Fireship presenting Nix in 100 seconds.
  • Nix Notes (⭐61) - A collection of short notes about Nix, each contributing to the same virtual machine image.
  • Nix Pills - The best way to learn, with examples.
  • Nix Shorts (⭐24) - A collection of short notes about how to use Nix, updated for Nix Flakes.
  • Nix Starter Config (⭐3.7k) - A few simple Nix Flake templates for getting started with NixOS + home-manager.
  • nix.dev - An opinionated guide for developers about getting things done using the Nix ecosystem.
  • NixOS & Flakes Book (⭐3.2k) - An unofficial and opinionated NixOS & Flakes book for beginners.
  • NixOS Asia Tutorial Series - A series of high-level tutorials on using Nix Flakes, NixOS, home-manager, etc.
  • NixOS in Production - Free (pay-what-you-want) book in pdf format.
  • Official Nix manual - Latest stable version of the official Nix manual, best used as reference guide. Receives updates when available.
  • Official NixOS manual - Latest stable version of the official NixOS manual, mix of tutorial and reference guide. Receives updates when available.
  • Official Nixpkgs manual - Latest stable version of the official Nixpkgs reference manual. Receives updates when available.
  • Tour of Nix - An online interactive tutorial on Nix language constructs.
  • Wombat's Book of Nix - A book-length introduction to Nix and flakes.
  • Zero to Nix - A flake-centric guide to Nix and its concepts created by Determinate Systems to quickly onboard beginners.

Discovery

  • Home Manager Option Search - Search through all 2000+ Home Manager options and read how to use them.
  • Nix Package Versions - Find all versions of a package that were available in a channel and the revision you can download it from.
  • nix-search-tv (⭐269) - CLI fuzzy finder for packages and options from Nixpkgs, Home Manager, and more.
  • Noogle - Nix API search engine allowing to search functions based on their types and other attributes.
  • NüschtOS Search (⭐160) - Simple and fast static-page NixOS option search.
  • Searchix - Search Nix packages and options from NixOS, Darwin and Home Manager.

Installation Media

  • nix-installer-scripts (⭐95) - Runs the official installer but does some tweaking as well such as adding fcontext for selinux and installing nix outside of the default profile so you don't accidently uninstall it.
  • nix-installer (⭐3.6k) - Opinionated alternative to the official Nix install scripts.
  • nixos-anywhere (⭐3.3k) - Install NixOS everywhere via SSH.
  • nixos-generators (⭐2.4k) - Take a NixOS config and build multiple different images types including VirtualBox VMs, Azure images, and installation ISOs.
  • nixos-infect (⭐1.9k) - Replace a running non-NixOS Linux host with NixOS.
  • nixos-up (⭐255) - Super easy NixOS installer that can be used from the installation ISO.

Channel History

  • npc - CLI to view and bisect Nixpkgs channel history.
  • Nix Infra Status - Get the age and current Git commit of each Nix channel.
  • Nix Review Tools Reports - Reports showing problematic dependencies (dependencies causing the most failed builds) for major Hydra jobsets.
  • nixpkgs PR tracker - A tracker for whether a PR has made it into a channel yet.

Deployment Tools

  • bento (⭐324) - A KISS deployment tool to keep your NixOS fleet (servers & workstations) up to date.
  • Clan - A peer-to-peer deployment tool with inbuilt support for secrets and a module system to manage distributed networks.
  • Colmena (⭐2.2k) - A simple, stateless NixOS deployment tool modeled after NixOps and morph.
  • comin (⭐929) - A deployment tool to continuously pull from Git repositories.
  • deploy-rs (⭐2.2k) - A simple multi-profile Nix-flake deploy tool.
  • krops - A lightweight toolkit to deploy NixOS systems, remotely or locally.
  • KubeNix (⭐498) - A Kubernetes resource builder using Nix.
  • KuberNix (⭐819) - Single-dependency Kubernetes clusters via Nix packages.
  • morph (⭐1k) - A tool for managing existing NixOS hosts.
  • Nixery (⭐2k) - A Docker-compatible container registry which builds images ad-hoc via Nix.
  • Nixinate (⭐291) - A Nix flake library to provide app outputs for managing existing NixOS hosts over SSH.
  • Nixlets - Like Helm but using only Nix, uses Kubenix under the hood.
  • NixOps (⭐2.2k) - The official Nix deployment tool, compatible with AWS, Hetzner, and more.
  • pushnix (⭐34) - Simple cli utility that pushes NixOS configuration and triggers a rebuild using ssh.
  • terraform-nixos (⭐413) - A set of Terraform modules designed to deploy NixOS.
  • terranix - Use Nix and the NixOS module system to write your Terraform code.

Virtualisation

  • extra-container (⭐297) - Run declarative NixOS containers from the command line.
  • microvm (⭐2.7k) - NixOS-based MicroVMs.
  • nixos-shell (⭐898) - Simple headless VM configuration using Nix (similar to Vagrant).

Command-Line Tools

  • alejandra (⭐1.4k) - An opinionated Nix code formatter optimized for speed and consistency.
  • angrr (⭐138) - Auto Nix GC Roots Retention. This tool simply deletes auto GC roots based on the modified time of their symbolic link target.
  • comma (⭐1.7k) - Quickly run any binary; wraps together nix run and nix-index.
  • deadnix (⭐766) - Scan Nix files for dead code.
  • devenv (⭐7.1k) - A Nix-based tool for creating developer shell environments quickly and reproducibly.
  • dix (⭐311) - Diff Nix; a super-fast tool to diff Nix related things.
  • manix (⭐422) - Find configuration options and function documentation for Nixpkgs, NixOS, and Home Manager.
  • nh (⭐2.9k) - Better output for nix, nixos-rebuild, home-manager and nix-darwin CLI leveraging dix and nix-output-monitor.
  • nix-alien (⭐838) - Run unpatched binaries on Nix/NixOS easily.
  • nix-diff (⭐487) - A tool to explain why two Nix derivations differ.
  • nix-du (⭐482) - Visualise which gc-roots to delete to free some space in your Nix store.
  • nix-index (⭐1.3k) - Quickly locate Nix packages with specific files.
  • nix-init (⭐1.4k) - Generate Nix packages from URLs with hash prefetching, dependency inference, license detection, and more.
  • nix-melt (⭐307) - A ranger-like flake.lock viewer.
  • nix-output-monitor (⭐1.6k) - A tool to produce useful graphs and statistics when building derivations.
  • nix-prefetch (⭐149) - A universal tool for updating source checksums.
  • nix-tree (⭐1k) - Interactively browse the dependency graph of Nix derivations.
  • nixfmt (⭐1.5k) - A formatter for Nix code, intended to easily apply a uniform style.
  • nixos-cli (⭐388) - Configurable all-in-one CLI for common NixOS tools with an emphasis on improved user experience.
  • nixpkgs-hammering (⭐333) - An opinionated linter for Nixpkgs package expressions.
  • nurl (⭐752) - Generate Nix fetcher calls from repository URLs.
  • nvd - Diff package versions between two store paths; it's especially useful for comparing NixOS generations on rebuild.
  • optnix - A terminal-based options searcher for Nix module systems.
  • statix (⭐927) - A linter/fixer to check for and fix antipatterns in Nix code.

Development

  • Arion (⭐901) - Run docker-compose with help from Nix/NixOS.
  • attic (⭐2k) - Multi-tenant Nix Binary Cache.
  • cached-nix-shell (⭐229) - A nix-shell replacement that uses caching to open subsequent shells quickly.
  • Cachix - Hosted binary cache service; free for open-source projects.
  • compose2nix (⭐862) - Generate a NixOS config from a Docker Compose project.
  • Conflake - A batteries included, autoload files, convention-based configuration framework for flake.nix.
  • Devbox (⭐12k) - Instant, portable, and predictable development environments.
  • devshell (⭐1.5k) - mkShell with extra bits and a toml config option to be able to onboard non-nix users.
  • dream2nix (⭐1.3k) - A framework for automatically converting packages from other build systems to Nix.
  • flake-utils-plus (⭐550) - A lightweight Nix library flake for painless NixOS flake configuration.
  • flake-utils (⭐1.6k) - Pure Nix flake utility functions to help with writing flakes.
  • flake.parts (⭐1.4k) - Minimal Nix modules framework for Flakes: split your flakes into modules and get things done with community modules.
  • flakelight (⭐404) - A modular flake framework aiming to minimize boilerplate.
  • flox (⭐4k) - Manage and share development environments, package projects, and publish artifacts anywhere.
  • gitignore.nix (⭐286) - The most feature-complete and easy-to-use .gitignore integration.
  • haumea (⭐413) - Filesystem-based module system for the Nix language similar to traditional programming languages, with support for file hierarchy and visibility.
  • lorri (⭐863) - A much better nix-shell for development that augments direnv.
  • make-shell (⭐35) - mkShell meets modules, a modular almost-drop-in replacement for pkgs.mkShell function.
  • MCP-NixOS (⭐738) - An MCP server that provides AI assistants with accurate information about NixOS packages, options, Home Manager, and nix-darwin configurations.
  • namaka (⭐144) - Snapshot testing for Nix based on haumea.
  • nil (⭐1.9k) - NIx Language server, an incremental analysis assistent for writing in Nix.
  • niv (⭐1.8k) - Easy dependency management for Nix projects with package pinning.
  • nix2container - An efficient container building workflow with Nix.
  • nix-direnv (⭐2.7k) - A fast loader and flake-compliant configuration for the direnv environment auto-loader.
  • nix-health (⭐48) - A program to check the health of your Nix install. Furthermore, individual projects can configure their own health checks in their flake.nix.
  • nix-oci (⭐105) - A flake-parts module for building minimal, reproducible OCI containers using nix2container.
  • nix-update (⭐825) - Update versions/source hashes of nix packages.
  • nixd (⭐1.4k) - Nix language server, based on Nix libraries.
  • nixpkgs-review (⭐621) - The best tool to verify that a pull-request in Nixpkgs is building properly.
  • Nixtest - Testing framework for Nix, with snapshot and unit test support, JUnit generation etc.
  • npins (⭐542) - A simple tool for handling different types of dependencies in a Nix project. It is inspired by and comparable to Niv.
  • pog (⭐181) - A new, powerful way to do bash scripts. Pog is a powerful Nix library that transforms the way developers create command-line interfaces (CLIs).
  • pre-commit-hooks.nix (⭐839) - Run linters/formatters at commit time and on your CI.
  • rnix-lsp (⭐710) - A syntax-checking language server for Nix.
  • robotnix (⭐792) - A declarative and reproducible build system for Android (AOSP) images.
  • services-flake (⭐747) - A NixOS-like service configuration framework for Nix flakes.
  • Snowfall Lib (⭐622) - A library that makes it easy to manage your Nix flake by imposing an opinionated file structure.
  • templates (⭐144) - Project templates for many languages using Nix flakes.
  • treefmt-nix (⭐619) - A formatter that allows formatting all your project files with a single command, all via a single .nix file.

DevOps

  • Nix GitLab CI - Define GitLab CI pipelines in pure Nix with full access to all Nix packages (incl. caching).
  • nixidy (⭐359) - Kubernetes GitOps with Nix and Argo CD.
  • Standard (⭐484) - An opinionated Nix Flakes framework to keep Nix code in large projects organized, accompanied by a friendly CLI/TUI optized for DevOps scenarios.

Programming Languages

Arduino

  • nixduino (⭐52) - Nix-based tool to help build Arduino sketches.

Clojure

  • clj-nix (⭐181) - Nix helper functions for Clojure projects.

Crystal

  • crystal2nix (⭐19) - Convert shard.lock into Nix expressions.

Elm

  • elm2nix (⭐124) - Convert elm.json into Nix expressions.

Gleam

  • nix-gleam (⭐66) - Generic Nix builder for Gleam applications.

Haskell

  • cabal2nix (⭐402) - Converts a Cabal file into a Nix build expression.
  • haskell-flake (⭐234) - A flake-parts Nix module for Haskell development.
  • haskell.nix (⭐627) - Alternative Haskell Infrastructure for Nixpkgs.
  • nix-haskell-mode (⭐29) - Automatic Haskell setup in Emacs.
  • nixkell (⭐121) - A Haskell project template using Nix and direnv.

Haxe

  • haxix (⭐5) - Nix flake to build haxe/Heaps.io projects.
  • kebab (⭐2) - Haxe packages for Nix.

Julia

  • Manifest2Nix.jl - A Nix library for creating reproducible Julia builds and experiments via precompilation.

Lean

  • lean4-nix (⭐113) - Nix flake build for Lean 4, and lake2nix.

Node.js

  • Napalm (⭐117) - Support for building npm packages in Nix with a lightweight npm registry.
  • node2nix (⭐589) - Generate Nix expression from a package.json (or package-lock.json) (to be stored as files).
  • npmlock2nix (⭐148) - Generate Nix expressions from a package-lock.json (in-memory), primarily for web projects.

OCaml

  • opam2nix (⭐93) - Generate Nix expressions from opam packages.

PHP

  • composer-plugin-nixify (⭐17) - Composer plugin to help with Nix packaging.
  • composer2nix (⭐92) - Generate Nix expressions to build composer packages.
  • composition-c4 (⭐13) - Support for building composer packages from a composer.lock (using IFD).
  • nix-phps (⭐82) - Flake containing old and unmaintained PHP versions (intended for CI use).
  • nix-shell (⭐179) - Nix shells for PHP development.

PureScript

  • Easy PureScript Nix (⭐209) - A project to easily use PureScript and other tools with Nix.
  • purs-nix (⭐82) - CLI and library combo designed for managing PureScript projects using Nix. It provides a Nix API that can be used within your projects, as well as a command-line interface for managing your development process.

Python

  • poetry2nix (⭐930) - Build Python packages directly from Poetry's poetry.lock. No conversion step needed.
  • uv2nix (⭐755) - Convert uv workspaces into pure Nix derivations.

Ruby

  • Bundix (⭐181) - Generates a Nix expression for your Bundler-managed application.
  • ruby-nix (⭐152) - Generates reproducible ruby/bundler app environment with Nix.

Rust

  • cargo2nix (⭐466) - Granular caching, development shell, Nix & Rust integration.
  • crane (⭐1.4k) - A Nix library for building Cargo projects with incremental artifact caching.
  • fenix (⭐1.1k) - Rust toolchains and Rust analyzer nightly for nix.
  • naersk (⭐996) - Build Rust packages directly from Cargo.lock. No conversion step needed.
  • nix-cargo-integration (⭐220) - A library that allows easy and effortless integration for Cargo projects.
  • nixpkgs-mozilla (⭐576) - Mozilla's overlay with Rust toolchains and Firefox.
  • rust-nix-templater (⭐48) - Generates Nix build and development files for Rust projects.
  • rust-overlay (⭐1.5k) - Pure and reproducible nix overlay of binary distributed Rust toolchains.

Scala

  • sbt-derivation (⭐75) - mkDerivation for sbt, similar to buildGoModule.

Zig

  • zig2nix (⭐180) - Flake for packaging, building and running Zig projects.
  • zon2nix (⭐118) - Convert the dependencies in build.zig.zon to a Nix expression.

NixOS Modules

  • base16.nix (⭐283) - Flake way to theme programs in base16 (⭐938) colorschemes, mustache template support included.
  • Home Manager (⭐10k) - Manage your user configuration just like NixOS.
  • impermanence (⭐1.8k) - Lets you choose what files and directories you want to keep between reboots.
  • musnix (⭐929) - Do real-time audio work in NixOS.
  • nix-bitcoin (⭐608) - Modules and packages for Bitcoin nodes with higher-layer protocols with an emphasis on security.
  • nix-darwin (⭐5.6k) - Manage macOS configuration just like on NixOS.
  • nix-mineral (⭐531) - Conveniently and reasonably harden NixOS.
  • nix-topology (⭐973) - Generate infrastructure and network diagrams directly from your NixOS configuration.
  • NixOS hardware (⭐3.2k) - NixOS profiles to optimize settings for different hardware.
  • NixOS-WSL (⭐3k) - Modules for running NixOS on the Windows Subsystem for Linux.
  • Nixvim (⭐2.9k) - A pre-packaged Neovim distribution built with Nix modules and Nixpkgs.
  • nvf (⭐1.6k) - A portable, modular Neovim configuration framework for Nix.
  • Self Host Blocks (⭐467) - Modular server management based on NixOS modules and focused on best practices.
  • Simple Nixos Mailserver - A complete mailserver, managed with NixOS modules.
  • Stylix (⭐2.3k) - System-wide colorscheming and typography for NixOS.

NixOS Configuration Editors

Desktop apps

  • Nix Software Center (⭐836) - Install and manage Nix packages. Desktop app in Rust and GTK.
  • NixOS Configuration Editor (⭐668) - Graphical editor for NixOS configuration. Desktop app in Rust and GTK.

Webinterface

  • MyNixOS - Graphical editor for Nix flakes. Create and manage configurations and modules for NixOS and Nix home-manager. Rather a Nix generator than a Nix editor, because it does not allow to import Nix files.

Overlays

  • awesome-nix-hpc (⭐101) - High Performance Computing package sets.
  • neovim-nightly-overlay (⭐416) - Daily bumped Neovim nightly package.
  • nixpkgs-firefox-darwin (⭐75) - Automatically updated Firefox binary packages for macOS.
  • nixpkgs-wayland (⭐618) - Bleeding-edge Wayland packages.
  • NUR (⭐1.9k) - Nix User Repositories. The mother of all overlays, allowing access to user repositories and installing packages via attributes.
  • System Manager (⭐1.6k) - A non-NixOS Linux system configuration tool built on Nix.
  • zig-overlay (⭐521) - A Nix flake packaging the Zig compiler. The flake mirrors the binaries built officially by Zig and does not build them from source.

Distributions

  • nixbsd (⭐990) - A NixOS fork with a FreeBSD kernel.
  • NixNG (⭐478) - A GNU/Linux distribution similar to NixOS. The defining difference is a focus on containers and lightweightness.
  • SnowflakeOS - A NixOS-based Linux distribution focused on beginner friendliness and ease of use.
