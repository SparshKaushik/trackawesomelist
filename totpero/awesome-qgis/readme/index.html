Awesome QGIS

Curated list of awesome QGIS plugins, resources, tutorials, and tools.

QGIS is a free, open-source, cross-platform geographic information system used for viewing, editing, and analyzing geospatial data.

Plugins

Data Management

  • QuickOSM - Download OpenStreetMap data directly using the Overpass API.
  • OSMDownloader - Download OSM data by selecting an area on the map.
  • Lat Lon Tools - Capture and zoom to coordinates in multiple formats.
  • mmqgis - Collection of vector layer operation tools including geocoding and merging.
  • KML Tools - Fast KML and KMZ import and export.
  • Digitizing Tools - Enhanced tools for vector geometry editing sessions.
  • Shape Tools - Create geodesic shapes, measure bearings, and flip coordinates.
  • Point Sampling Tool - Sample raster and polygon values at point locations.
  • GeoCoding - Forward and reverse address lookup via Nominatim and Google.
  • Zornade Italian Parcel Downloader - Download enriched Italian cadastral parcels with 110+ attribute fields (terrain, demographics, land use, OMI valuation, hydrogeological risk) via the free Zornade API.

Basemaps and Web Services

  • QuickMapServices - Easy basemap addition from OpenStreetMap, Google, Bing, and more.
  • HCMGIS - Basemaps, OpenData download, and batch conversion tools.
  • Street View - Google Street View and other street-level imagery integration.
  • MetaSearch Catalogue Client - Interact with OGC CSW metadata catalogue services.
  • GeoBasis Loader - Quick insertion of free geoservices and basemaps.

Analysis and Processing

  • Profile Tool - Plot terrain profiles from raster layers.
  • Processing SAGA NextGen Provider - Processing provider for modern SAGA GIS releases.
  • LF Tools - Cartographic production, surveying, drone mapping, and GNSS tools.
  • ArcGeek Calculator - Coordinate calculations, conversions, and watershed analysis.
  • Fast Density Analysis - Fast kernel density visualization for geospatial analytics.

Remote Sensing

  • Semi-Automatic Classification Plugin - Supervised classification of remote sensing imagery.
  • Google Earth Engine Plugin - Google Earth Engine integration for satellite data processing.
  • SRTM-Downloader - Download SRTM elevation tiles from NASA.
  • OpenTopography DEM Downloader - Download DEM data from OpenTopography.org.
  • Freehand Raster Georeferencer - Interactive raster georeferencing by dragging and scaling.
  • AI Segmentation by TerraLab - Point-and-click AI segmentation of buildings, trees and any object into vector polygons, with a free local mode.

Symbology and Cartography

  • SLYR Community Edition - Convert ESRI Style, LYR, and MXD files to QGIS symbology.
  • LAStools - Process point cloud data in LAS and LAZ formats.
  • QuickWKT - Quick WKT and WKB geometry viewer and loader.

3D and Visualization

  • Qgis2threejs - Export 3D visualizations powered by three.js.
  • 3DCityDB Tools - Visualize and manipulate CityGML data from 3D City Database.
  • GEarthView - Display QGIS view in Google Earth.

Web Publishing

  • qgis2web - Export projects to OpenLayers or Leaflet web maps.
  • QGIS Cloud Plugin - Publish maps directly on qgiscloud.com.
