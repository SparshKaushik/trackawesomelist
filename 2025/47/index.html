1. Awesome Zsh Plugins

Plugins / superconsole - Windows-only

  • clean-history (⭐0) - Smart ZSH history cleanup plugin that automatically removes typos and failed commands based on similarity analysis.
  • deja-vu (⭐3) - Logs and retrieves command history based on the directory it was run in. Never forget that complex docker or git command you ran in a project folder weeks ago.
  • ding (⭐0) - Plays notification sounds when a long-running shell command completes.
  • git-worktree (alexiszamanidis) (⭐34) - Wraps some git worktree operations for simplicity and productivity. Includes fzf (⭐75k) tooling.
  • git-worktree (trthomps) (⭐1) - Enhanced git worktree management with bare repository support. This plugin provides convenient commands for working with git worktrees, making it easy to work on multiple branches simultaneously.
  • seedee (⭐6) - Navigate interactively through directories / history of visited directories using arrow keys from command line.
  • shell-ng (⭐5) - Combines several of joknarf's other plugins - selector (⭐13), nerdp (⭐3), redo (⭐9), seedee (⭐6) and complete-ng (⭐3).

Completions / superconsole - Windows-only

  • complete-ng (⭐3) - Replace ZSH completion multiple choices output by interactive selector menu, browse directories inside the menu, view/edit files directly from the menu.

Themes / superconsole - Windows-only

  • fishbone++ (⭐16) - A theme influenced by oh-my-fish (⭐11k) theme fishbone and oh-my-zsh theme typewritten (⭐930). Includes decorators for current directory, git status, exit status of last command.
  • pumpkane (⭐0) - A modern, colorful, and informative theme designed for clarity, aesthetics, and productivity. It features dynamic colors, git status integration, time-based coloring, and optional nickname display
  • yuni (⭐0) - A modern version of the macOS default ZSH theme, adding essential developer features the original theme lacked. Includes decorators for the exit code of failed commands, your user and host names, the current directory path shortened, the active branch, and privilege decorators: % if you're a normal user, # if root, and [!] when you don't have permissions to modify the current directory. Works on macOS 14 Sonoma or later.
